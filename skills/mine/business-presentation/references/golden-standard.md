# 黃金標準：從範例簡報提取的設計規範

本文件整理自三份符合期待的範例簡報，作為製作簡報時的視覺與內容品質基準。

來源範例：
- 「2025年度計畫.pptx」— 內部年度策略報告（深藍主題，重文字結構）
- 「Fund Platform Partnership Proposal」— 對外合作提案（黑白灰主題，圖文並茂）
- 「Reconstructing the Growth Engine」— 策略行動提案（淺藍灰主題，數據驅動）

---

## 一、標題規範（最重要）

三份範例的共同特徵：**每頁標題都是完整的結論句，佔據頁面最頂端 15-20% 的空間**。

好的標題範例（直接取自範例簡報）：
- 「殘酷的數學題：我們每獲得一個新下載，平均虧損 5 元」
- 「盲目的規模化，只會帶來線性放大的虧損」
- 「Fund market has 5% CAGR in past 5 years, and MAU will reach 9.6 trillion in 2033」
- 「2024 年用組織調整帶來的力量，2025 將順流而行各事業組織的同步，用有限的資源預算做，用 Finlab 做創新嘗試」
- 「GenAI 應用對於營銷內容創作，且能改變 SEO 的關鍵排名，開始為用戶完成 2 大需求面向」

差的標題（應避免）：
- 「市場分析」「Q3 營收」「行動方案」「資源需求」

### 標題格式規範
- 字體大小：24-32pt 粗體（中文建議更大）
- 顏色：深色背景用白色，淺色背景用黑色/深藍
- 位置：頁面最頂端，左對齊
- 行數：最多 2-3 行，超過就精簡

## 二、頁面結構規範

### 佈局模式 A：三段式（標題 + 內容 + 底部區域）

適用場景：頁面資訊量大、讀者可能迷失重點時，底部元素幫助「收束」。

```
┌─────────────────────────────────────┐
│  標題區（15-20%）                      │
│  結論句標題，大字粗體                    │
├─────────────────────────────────────┤
│                                     │
│  內容區（60-70%）                      │
│  圖表 / 卡片 / 對比 / 流程            │
│  使用項目符號的結構化內容              │
│                                     │
├─────────────────────────────────────┤
│  底部區域（10-15%）                    │
│  洞見條 / 強調條 / 引言條 / 來源標注    │
└─────────────────────────────────────┘
```

### 佈局模式 B：二段式（結論+洞見合一標題 + 內容）

適用場景：標題本身已經包含完整的「事實 + 意義解讀」時，不需要額外底部元素。

```
┌─────────────────────────────────────┐
│  結論+洞見標題區（15-20%）              │
│  包含事實陳述 + 意義解讀的完整標題       │
├─────────────────────────────────────┤
│                                     │
│  內容區（75-85%）                      │
│  圖表 / 卡片 / 對比 / 流程            │
│  使用項目符號的結構化內容              │
│  （可在底部加來源標注，但非必需）       │
│                                     │
└─────────────────────────────────────┘
```

**判斷使用哪種佈局的原則**：
- 標題已經同時回答了「是什麼」和「所以呢」→ 用模式 B
- 標題只陳述結論，需要額外一句話解讀數據意義 → 用模式 A
- 封面、章節分隔頁、KPI 展示頁、UX 展示頁 → 通常不需要底部元素

範例對照（來自 Fund Platform Proposal）：
- 模式 B 標題：「Fund market has 5% CAGR in past 5 years, while FundRich achieves 37% CAGR as 7 times than industry avg.」→ 標題已含洞見，底部只放 Source 標注
- 模式 A 標題：「Banks are shifting to offensive strategies by offering digital investment with zero transaction and custody fees」→ 底部加紅底強調條：「To establish competitive advantages, we should move beyond traditional 'pure fund platform'」

### 底部區域的多種形態

底部區域不限於灰底 Insight Bar，根據頁面功能選擇合適的形態：

| 形態 | 視覺特徵 | 適用場景 | 函式 |
|------|----------|----------|------|
| 洞見條（Insight Bar） | 淺灰底 #E8E8E8 + 粗體關鍵訊息 | 資訊量大、需收束重點的分析頁 | `addInsight()` |
| 強調條（Highlight Bar） | 紅底/深色底 + 白色文字 | 全簡報最關鍵的 1-2 個結論 | `addBottomBar(style:"highlight")` |
| 引言條（Quote Bar） | 引號 + 斜體 + 人物標注 | 用戶體驗展示、客戶證言 | `addBottomBar(style:"quote")` |
| 來源標注（Source Bar） | 小字灰色 + Source: xxx | 數據頁的資料來源 | `addBottomBar(style:"source")` |
| 無底部元素 | — | 封面、分隔頁、KPI、UX 展示 | 不呼叫任何底部函式 |

Insight Bar 範例（仍可使用）：
- 「Insight: growing driver of fund platform is investor behaviors' shifting」
- 「透過底層單位的修復，我們將達成一億營收的難度降低了整整 3 倍」
- 「只要讓用戶相信『這能讓我提分』，轉換率將發生結構性跳躍。」

### 輕量章節標記

三份範例都使用帶圈數字（①②③④⑤）貫穿全簡報，讓讀者隨時知道自己在哪個章節。不需要獨立佔用一整頁的分隔頁，而是嵌在內容頁的左上角。

```
┌─────────────────────────────────────┐
│ ① │  結論句標題                        │
│    │  ....                            │
```

使用 `addChapterMarker(s, number)` 在頁面左上角放置小圈號 + 章節名。適用於 5 頁以上的簡報，幫助讀者導航。

### 左右分欄作為核心佈局

左右分欄是三份範例中出現頻率最高的佈局模式，用途遠超「對比」：

| 左欄內容 | 右欄內容 | 來源範例 |
|----------|----------|----------|
| 競爭對手截圖 | 3 Critical Questions | Fund Platform Proposal |
| 2×2 象限圖 | Opportunity 文字說明 | Fund Platform Proposal |
| App 截圖群組 | 用戶引言 | Fund Platform Proposal |
| 外部夥伴資源 | 自有能力資源 | Fund Platform Proposal |
| 組織架構圖 | 治理原則（①②③） | Fund Platform Proposal |
| 投資行為信號 | 消費交易信號 | Eagle Alpha Fireside Chat |
| 2C 消費者 | 2B 企業服務 | AI Strategy PPTX |

使用 `slideSplitLayout()` 作為通用左右分欄函式，或使用 `slideComparison()` / `slideFromTo()` 等特化版本。

## 三、背景色與視覺節奏

### 背景色循環模式
原始範例採用「深淺交替」的節奏感。下表為 Gary Chen 品牌規範下對應色票（**禁用純黑，深色一律用 Midnight Navy 取代**）：

| 頁面類型 | 背景色 | 用途 |
|--------|--------|------|
| 封面/分隔頁 | Midnight Navy #050F1A 或 Gary Navy #091F33 | 開場、章節切換 |
| 內容/數據頁 | 白色 #FFFFFF | 需要清晰閱讀的內容 |
| 分析/洞見頁 | 冷調淺灰 #EEF2F6 或微灰白 #F8FAFB | 分析、對比、框架 |
| 重點/CTA 頁 | Gary Navy #091F33 | 結論、決策要求 |

### 建議背景節奏（8 頁簡報為例）
1. Midnight Navy（封面/議程）
2. 白色（數據展示）
3. 冷調淺灰（分析）
4. 白色（方案 A）
5. Midnight Navy（方案 B — 製造對比感）
6. 白色（資源）
7. 冷調淺灰（預測/路線圖）
8. Gary Navy（決策 CTA）
