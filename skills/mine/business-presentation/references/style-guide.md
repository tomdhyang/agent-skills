# 簡報風格指南：內容風格與視覺效果

製作簡報建議時，需要先確認用戶的「內容風格」和「視覺效果」偏好，然後據此調整故事線結構、用詞語氣、版型選擇。

---

## 內容風格（9 種）

### 1. 專業風格
- **特徵**：精準、邏輯、嚴謹，框架化表達
- **適用場景**：企業匯報、戰略溝通、技術述職
- **語言特點**：使用專業術語，數據引用精確，論證鏈條完整
- **SCQA 建議**：使用 S-C-Q-A 經典順序或 A-S-C-Q 結論先行
- **頁面結構**：結論標題 + 分點論述 + 數據佐證

### 2. 簡潔風格
- **特徵**：減少裝飾性內容，保留一級/二級標題，結構乾淨利落
- **適用場景**：快速閱讀、高管場景
- **語言特點**：字數極少，每頁一個核心訊息
- **SCQA 建議**：A（僅結論）或 A-S-C-Q
- **頁面結構**：大標題 + 關鍵數字/短句，無多餘元素

### 3. 具象比喻風格
- **特徵**：貼近生活的例子、比喻、類比
- **適用場景**：面向小朋友、非專業受眾群體
- **語言特點**：口語化、用生活場景解釋抽象概念
- **SCQA 建議**：S-C-Q-A 經典順序（需要完整背景鋪墊）
- **頁面結構**：比喻圖示 + 簡短說明，圖文比例偏重圖

### 4. 故事化風格
- **特徵**：以敘事鏈條組織，用「背景—衝突—解決—結果」模型推動
- **適用場景**：產品發佈、經驗分享
- **語言特點**：敘事性強，有起承轉合，情感共鳴
- **SCQA 建議**：嚴格遵循 S-C-Q-A 順序，不跳過任何環節
- **頁面結構**：情境描繪 → 問題凸顯 → 方案呈現 → 成果展示

### 5. 資料驅動風格
- **特徵**：強調數據、指標、趨勢、對比分析
- **適用場景**：商業分析、調研報告
- **語言特點**：數字為主角，用數據結論驅動邏輯
- **SCQA 建議**：A-S-C-Q（結論先行，數據佐證）
- **頁面結構**：數據標題 + 圖表 + 洞見標註

### 6. 教學風格
- **特徵**：循序漸進，解釋概念、舉例說明、對比差異、步驟演示
- **適用場景**：教學、培訓類
- **語言特點**：引導性語言，先概念後實例，適度重複重點
- **SCQA 建議**：S-C-Q-A（完整鋪墊背景）
- **頁面結構**：概念定義 → 範例 → 對比 → 練習/思考

### 7. 激勵風格
- **特徵**：鼓舞語氣和積極願景，強調「為什麼重要」「我們要做什麼」
- **適用場景**：團隊動員、年度啟動會、願景介紹
- **語言特點**：積極正面、語句有力、面向未來
- **SCQA 建議**：C-Q-S-A（先衝突後解方，營造緊迫感和希望感）
- **頁面結構**：願景描繪 + 行動號召 + 團隊承諾

### 8. 產品展示風格
- **特徵**：突出場景鏡頭、用戶價值、功能亮點、體驗流程
- **適用場景**：新品發佈、方案宣講
- **語言特點**：強調「好處和使用方式」，面向用戶價值
- **SCQA 建議**：C-Q-S-A 或 A-S-C-Q
- **頁面結構**：痛點 → 解決方案 → 功能展示 → 效果呈現

### 9. 思維導圖風格
- **特徵**：概念之間的關聯為主線，層次化結構展開知識網路
- **適用場景**：複雜主題
- **語言特點**：概念間關聯清晰，層次分明
- **SCQA 建議**：S-C-Q-A（需完整鋪墊）
- **頁面結構**：中心概念 → 分支展開 → 層級細化

## 視覺效果（10 種）

### 1. 極簡留白
- **特徵**：大量留白、弱化裝飾、突出內容主體
- **適用場景**：專業場景、高管簡報
- **版型傾向**：選擇文字少、空間大的版型
- **推薦 Slide Library 版型**：簡潔 Agenda (p.9)、Next Steps (p.10)

### 2. 強調色塊
- **特徵**：大色塊和模組化佈局強化層級關係
- **適用場景**：方案展示、營運復盤
- **版型傾向**：選擇色塊分區明顯的版型
- **推薦版型**：Comparison (p.17)、2×2 Quadrant (p.20)、Key Drivers (p.118)

### 3. 卡片式佈局
- **特徵**：卡片、分區、分欄組織內容
- **適用場景**：內容較多、結構化資訊
- **版型傾向**：網格、多欄卡片式版型
- **推薦版型**：Agenda Grid (p.6)、6 Column List (p.116)、Next Steps Dense (p.11)

### 4. 圖示驅動
- **特徵**：統一風格圖示、符號表達概念，降低文字密度
- **適用場景**：流程講解、結構說明
- **版型傾向**：帶圖示的流程或框架版型
- **推薦版型**：Process Deep-dive with Icons (p.58)、Six Pillars (p.67)、SMART (p.68)

### 5. 插畫或手繪感
- **特徵**：柔和插畫或輕鬆手繪筆觸，增強親和力
- **適用場景**：科普、教學、文化主題
- **版型傾向**：圖文混排，適度留白
- **推薦版型**：Journey Teamwork (p.88)、Compass (p.41)

### 6. 科技質感
- **特徵**：線條、漸變、光效建構輕科技氛圍
- **適用場景**：AI、資料、網際網路主題
- **版型傾向**：深色背景、線條圖表
- **推薦版型**：Dashboard Spider (p.60)、Flow Charts (p.59)

### 7. 白色主題
- **特徵**：白色背景配深色文字，強對比，穩重與衝擊力
- **適用場景**：正式場景、資料展示
- **版型傾向**：白底深字，清晰間距
- **推薦版型**：Bar Chart (p.13)、3 Column Text Table (p.131)

### 8. 資訊可視化
- **特徵**：圖表、趨勢圖、結構圖作為主視覺
- **適用場景**：分析匯報、研究報告
- **版型傾向**：數據圖表為核心
- **推薦版型**：Range Quantitative (p.15, 18)、Waterfall (p.22)、Scatter (p.25)

### 9. 分鏡敘事
- **特徵**：類似電影分鏡的結構，內容具故事流動感
- **適用場景**：產品發佈、戰略敘述
- **版型傾向**：時間軸、旅程圖
- **推薦版型**：Journey Upward Arc (p.83-84)、Journey Up and Down (p.87)

### 10. 品牌一致
- **特徵**：嚴格遵循品牌色、字型體系與風格規範
- **適用場景**：外部宣講、品牌官方材料
- **版型傾向**：統一風格，所有頁面保持一致
- **推薦版型**：Logo Coloring (p.126)、Practice at a Glance (p.127)

## 風格組合建議

常見的內容風格 × 視覺效果配對：

| 內容風格 | 推薦視覺效果 |
|----------|-------------|
| 專業 | 極簡留白、白色主題 |
| 簡潔 | 極簡留白、強調色塊 |
| 具象比喻 | 插畫或手繪感、圖示驅動 |
| 故事化 | 分鏡敘事、強調色塊 |
| 資料驅動 | 資訊可視化、白色主題 |
| 教學 | 圖示驅動、卡片式佈局 |
| 激勵 | 強調色塊、分鏡敘事 |
| 產品展示 | 科技質感、分鏡敘事 |
| 思維導圖 | 圖示驅動、卡片式佈局 |
