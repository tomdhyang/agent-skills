# Gary Chen 品牌色彩規範

Gary Chen 個人品牌（科技 / AI 主題）官方色系。所有簡報產出必須使用此規範。

---

## 主色系（Primary Palette）

| 角色 | 色名 | HEX | 用途 |
|------|------|-----|------|
| **品牌主色** | Gary Navy | `091F33` | 頂部橫條、章節分隔頁深底、Logo 色、主標題強調、CTA 按鈕 |
| **品牌強調** | Electric Blue | `1E77E9` | 卡片頂邊條、數據強調、互動元素、第二層次強調 |
| **更深 Navy** | Midnight Navy | `050F1A` | 章節分隔頁背景（替代純黑） |
| **主文字色** | Near Black | `0A0E14` | 標題文字、主要內文 |
| **副文字色** | Slate Gray | `5A6573` | 次要說明文字、圖表標籤 |
| **背景白** | White | `FFFFFF` | 內容頁主背景 |
| **冷調淺灰** | Cool Gray | `EEF2F6` | 交替頁面背景、表格斑馬紋、卡片底色、Insight Bar |
| **微灰白** | Off White | `F8FAFB` | 卡片底色（比 Cool Gray 更淺） |

## 輔助色（Secondary Palette）

| 角色 | 色名 | HEX | 用途 |
|------|------|-----|------|
| **中灰** | Medium Gray | `8A95A5` | 說明文字、邊框、分隔線旁文字 |
| **深底副文字** | Light Steel | `C4CCD6` | 深色背景頁面的副文字 |
| **分隔線** | Divider Gray | `D8DEE5` | 標題與內容之間的分隔線、表格框線 |

## 隱藏警示色（Restricted Palette）

| 角色 | 色名 | HEX | 用途（僅限） |
|------|------|-----|-------------|
| **警示紅** | Signal Red | `C8463C` | Risk matrix 高嚴重度標記、專案狀態紅燈、負成長數字 |

**注意：警示紅僅限以上三種場景使用，不作為主視覺語言。** 一般「強調」「重點」「結論」一律使用 Gary Navy `091F33` 或 Electric Blue `1E77E9`。

---

## 色彩使用限制（Strict Rules）

1. **禁用黑底 / 純黑背景** — 所有頁面背景只用 `FFFFFF`、`EEF2F6`，深色頁面用 `091F33` 或 `050F1A` 取代純黑。
2. **禁用紅、橘、黃、綠** 等暖色系作主視覺強調。整份簡報只走 Navy + Electric Blue + 灰階。
3. **「達成 / 正面 / 重點」** → 用 `1E77E9` Electric Blue 或粗體 + Navy。
4. **「問題 / 落後 / 警示」** → 用粗體 + Slate Gray，或在極少數狀態指示場景下用 `C8463C`。
5. 警示紅 `C8463C` **不能用於**：標題文字、頂部條、主要強調、卡片邊條、CTA。

## 字體規範

| 用途 | 字體 | Fallback |
|------|------|----------|
| **主字體（中英共用）** | `Noto Sans TC`（思源黑體繁中） | 系統預設無襯線字體 |

**為什麼選 Noto Sans TC：**
- Google Fonts 開源、跨平台支援好（macOS / Windows / Linux 皆可下載安裝）
- 中文字形現代專業，拉丁字符使用 Source Sans Pro 設計，雙語混排不衝突
- AI / SaaS / 科技產品場景普遍使用，符合 Gary Chen 品牌調性

**pptxgenjs 用法：** 所有 `addText` 統一設定 `fontFace: "Noto Sans TC"`，PowerPoint 與 LibreOffice 在缺字時會自動 fallback 到系統字體。

## 視覺元素規範

### 頂部品牌條（每頁必備）
- 顏色：`091F33` Gary Navy
- 高度：4-6px（約 0.04-0.06 吋）
- 位置：頁面最頂端，全寬
- 用途：品牌識別，統一所有頁面的視覺一致性

### 卡片頂邊條
- 顏色：`1E77E9` Electric Blue（主）或 `091F33` Navy（強調）
- 高度：5-6px
- 用途：卡片頂部彩色邊條，區分不同卡片類別

### 分隔線
- 顏色：`D8DEE5` Divider Gray
- 高度：2px
- 用途：標題與內容之間的視覺分隔

### Insight Bar（底部洞見條）
- 背景色：`EEF2F6` Cool Gray
- 文字色：`0A0E14` Near Black（粗體）
- 高度：約 0.5 吋
- 位置：頁面底部

### 章節分隔頁
- 背景色：`050F1A` Midnight Navy 或 `091F33` Gary Navy
- 編號 / 標題文字色：`FFFFFF`
- 副文字色：`C4CCD6` Light Steel

## pptxgenjs 色彩常量

在 pptxgenjs 中使用以下常量：

```javascript
const C = {
  // 核心品牌色
  primary: "091F33",      // Gary Navy - 頂部條、主強調、CTA
  accent: "1E77E9",       // Electric Blue - 卡片邊條、第二強調
  primaryDark: "050F1A",  // Midnight Navy - 章節分隔頁深底

  // 文字
  nearBlack: "0A0E14",    // 主文字
  darkGray: "5A6573",     // 副文字
  midGray: "8A95A5",      // 說明、邊框
  lightText: "C4CCD6",    // 深底頁面副文字

  // 背景
  white: "FFFFFF",        // 主背景
  offWhite: "F8FAFB",     // 卡片底（最淺）
  lightGray: "EEF2F6",    // 交替背景、Insight Bar
  divider: "D8DEE5",      // 分隔線、表格框

  // 隱藏警示色（極少使用）
  warning: "C8463C",      // 僅 risk matrix / 狀態紅燈 / 負成長
};

const FONT = "Noto Sans TC";  // 統一字體
```

## 色彩使用語義

| 語義 | 應使用的顏色 |
|------|----------|
| 品牌識別 / 主強調 | `091F33` Gary Navy（頂部條、主標題色塊） |
| 第二強調 / 數據亮點 | `1E77E9` Electric Blue（卡片邊條、大數字、互動元素） |
| 達成 / 正面 / 目標 | `1E77E9` Electric Blue 加粗 |
| 中性 / 背景 / 說明 | `5A6573` / `8A95A5` |
| 警示 / 落後（極少用） | `C8463C` 僅限 risk matrix、狀態紅燈、負成長 |
| 深色強調背景 | `091F33` 或 `050F1A`（章節分隔頁、深色 CTA） |
